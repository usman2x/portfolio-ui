Data Landscape Scanner

A data discovery and governance system supporting 40+ technologies for cataloguing, lineage, and classification.

JavaReactSQLSnowflake

Explore the external reference for additional context around the project.

View project reference

Where governance was breaking down

Enterprise teams needed one dependable way to discover, classify, and trace data assets across databases, warehouses, BI tools, and cloud platforms. Coverage gaps and inconsistent metadata discovery made governance harder as the ecosystem expanded.

  • Data assets lived across a wide mix of technologies.
  • Metadata discovery quality varied from connector to connector.
  • Security concerns around scanner-side query behavior increased operational risk.

How the scanner became more useful

The platform was expanded to support broader technology coverage, stronger metadata discovery, and safer execution patterns. The work focused on making cataloguing and lineage dependable enough for real enterprise adoption.

What I was responsible for

My contribution spanned connector delivery, scanner hardening, and metadata improvement work across multiple technologies.

  • Built and improved connectors for systems including dbt, Kafka, and Power BI.
  • Mitigated SQL injection risks and tightened scanner-side query safety.
  • Implemented tag discovery for database objects to improve classification workflows.
  • Optimized scanner behavior for Azure Synapse, Databricks, and Snowflake.

What changed as a result

  • Expanded discovery coverage across a broader set of enterprise technologies.
  • Improved governance readiness with stronger classification and tagging support.
  • Reduced operational risk by hardening query execution and connector behavior.
  • Made lineage and cataloguing more dependable for large heterogeneous estates.
